# 📌 Overview

Resume Intel AI is an intelligent recruitment assistant that helps recruiters and hiring teams analyze resumes using **semantic similarity**, **skill extraction**, and **AI-powered candidate ranking**.

Unlike traditional Applicant Tracking Systems (ATS) that rely only on keyword matching, this system understands the **meaning** behind resume content using transformer embeddings.

The platform compares resumes against job descriptions and provides:

✅ Candidate match score  
✅ Skill gap analysis  
✅ Missing skill detection  
✅ Candidate ranking  
✅ Explainable AI insights  

---

# ✨ Features

## 🧠 Semantic Resume Matching

Uses transformer embeddings to understand contextual similarity between:

- Candidate resumes
- Job descriptions

No simple keyword matching.

Real semantic understanding.

---

## 📊 Candidate Ranking

Automatically ranks candidates based on:

- Semantic relevance
- Skill overlap
- Job fit

---

## 🔍 Skill Extraction

Detects technical skills such as:

- Python
- Machine Learning
- Deep Learning
- NLP
- SQL
- PyTorch
- TensorFlow
- Docker
- FastAPI
- AWS
- Azure

and more...

---

## 💡 Explainable AI

Provides recruiter-friendly explanations like:

> Matched 8 required skills.  
> Missing 2 required skills.

Modern UI built with Streamlit:

# ⚙️ Installation

## 1. Clone Repository

```bash
git clone <your-repo-url>
cd resume-intel-ai
```

---

## 2. Create Virtual Environment

```bash
python -m venv venv
```

Activate environment:

### Windows

```bash
venv\Scripts\activate
```

### Mac/Linux

```bash
source venv/bin/activate
```

---

## 3. Install Dependencies

```bash
pip install -r requirements.txt
```

---

# ▶️ Run Application

```bash
streamlit run app.py
```

Application will launch locally.
